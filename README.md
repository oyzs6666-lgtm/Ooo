# 今日热量累积柱版

这是独立的累积柱版本。记录页记录食物名称、热量和系统时间；统计页把每次摄入由下向上累加为一根全天热量柱。

## 累积柱

- 纵坐标 0–1800 kcal，每 100 kcal 一格，1800 以上压缩为一格
- 每次记录是一个独立色块，柱顶显示当日总热量
- 色块右侧标注食物名称和该组热量
- 拖动一个色块覆盖另一个色块，确认后合并
- 长按已合并色块，确认后恢复原记录；未合并色块不可拆解

## 热量分区与颜色

- 每个色块按该组热量在墨绿—绿—黄—橙—红色带中的精确位置取一种纯色
- 合并后的色块按合计热量重新计算纯色
- 柱子保留轻微圆角，选中与拖动目标会显示边框

网页数据和合并关系都使用独立的浏览器本地存储，不会与原有网站混合。
